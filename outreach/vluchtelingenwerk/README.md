# Campagne — VluchtelingenWerk (train-de-trainer + curriculum per locatie)

Follow-up op de eerdere kennismaking. Doel: locaties van VluchtelingenWerk
Oost-Nederland binnen ~50 km van Enter (7468HH) benaderen met een concreet
aanbod:
1. **Train-de-trainer** — begeleiders/vrijwilligers nieuwe-media-vaardigheden leren.
2. **Curriculum per locatie** — lesmateriaal afgestemd op de specifieke groep daar.

Open, vrijblijvend gesprek. Verwijzing naar workshops-site én LinkedIn.

## Bestanden
- **`mails/01-locatie-train-de-trainer.md`** — concept in Kevins voice, met beide links.
- **`locaties-tracker.csv`** — locaties, adressen, status.

## Het adres-probleem (belangrijk)
VluchtelingenWerk publiceert géén uniform e-mailadres per locatie:
- Sommige locaties: `[plaats]@vluchtelingenwerk.nl` (bv. `goor@vluchtelingenwerk.nl`).
- AZC-locaties: `azc[plaats]@vluchtelingenwerk.nl` (bv. `azcalmelo@`).
- Enschede/Hengelo/Deventer: alleen telefoon publiek.
- Nijverdal: loopt via een ándere organisatie (Stichting De Welle).

De locatie-finder (waar Kevin 7468HH invulde) is dus de betrouwbaarste bron,
maar die is niet automatisch uit te lezen (403).

## Twee routes
- **A) Per locatie** — zoals Kevin wil, curriculum op maat per groep. Vergt de
  finder-lijst (naam + plaats per locatie) → dan verifieer ik de adressen en
  maak ik per locatie een concept. **Plak de finder-resultaten en ik vul aan.**
- **B) Regionaal** — VluchtelingenWerk Oost-Nederland centraal benaderen voor
  een train-de-trainer-programma over meerdere locaties. Vaak is dít het
  niveau waar zo'n programma besloten wordt. Kan als aanvulling op A.
